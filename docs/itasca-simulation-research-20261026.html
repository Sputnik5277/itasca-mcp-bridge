02

桥接运行层先解决执行与取数

已核 itasca-mcp 当前 README 将十个工具分为五个文档工具和五个执行工具；执行侧需要引擎内桥接。可从 addon.py 和 桥接客户端源码 进入，README 中的操作演示用于理解连接方式。

它提供调用模型、读取状态和导出数据的通道。煤岩接触本构、含水分组与加载路径仍需建模技能和研究者定义。此前笔记中的另一台电脑、四套 server 与旧桥接协议仅为历史快照，本轮没有核实当前电脑运行栈，也不据此替换现役配置。桥接本身不具备作为 colorplot 绘图卡的输入输出闭环。

03

建模与试验模拟从煤岩靶标开始

建议以 pfc-codex-skills 的标准试验和脆性岩石专题为主要候选，先建立干燥基准，再按实测浸水组标定弹性模量、峰值强度与破坏形态。含水作用如何映射到胶结刚度、强度或摩擦参数，需要实验与机制依据；仅降低一个参数不足以说明水致损伤机制。

批量工况可参考参数化仓的 PFC3D 示例配置与试样模板。已读配置采用 PFC9，扫描摩擦与刚度，默认提取接触数、颗粒数和不平衡比；UCS 标定仍需自行实现提取函数，不能把示例命名当作完整强度标定结果。

asphalt 仓明确限定 PFC5 沥青材料。可借其数据契约与离线后处理组织方法；Burger、Marshall 和车辙参数不直接迁移到煤岩。

04

后处理把曲线、力链与裂纹连起来

PFC 技能包已提供 plot_curves.py、场图和玫瑰图脚本；三维入口是 pfc_export.py 与 view_balls.py。已读导出契约列出颗粒位置、位移、接触法向力、裂纹中心和类型，并要求确认力的正负号及裂纹尺寸约定。

建议按峰前、峰值、峰后三个力学阶段对齐应力—应变、力链重排和张剪裂纹空间分布，再与 DIC 局部化带比较。表面 DIC 与内部颗粒场的观测范围不同，先统一坐标和阶段，再讨论空间对应。

可跳转查看 asphalt 仓的已有示例帧与动画说明。这是仓库教学素材入口，本轮未逐像素审图，不作为本研究结果。

05

AE 能量需要明确事件与量纲

旧笔记把 pfc-ae-energy 描述为纯参考资料；当前树中已见 heavy-ae 模板，含裂纹回调、导出 FISH 和多种绘图脚本。已读 plot_ae_energy.py开头包含 CSV 读取、积分与应变求导，并依赖案例 config；这仍是待适配模板。

建议分别记录断键、聚类事件、模型能量项和仪器 AE 能量，明确单位、时间窗、聚类规则及采样间隔，再比较累计变化与突增阶段。不能将一次断键等同一次实测 AE 事件，也不能直接把模型能量当仪器能量值；论文1_2可优先检验其与应变局部化是否同步。

06

论文图与可复用源码怎样交付

建议保留“输入数据—字段与单位—处理脚本—配置—图件”的完整链路。曲线和参数响应图可在数据契约稳定后评估接入 colorplot；力链、裂纹三维渲染应保留专用后端与相机配置。参数化仓的 plot.py已核为 results.csv 驱动的基础 PNG 绘图入口，仍需另做论文排版适配。

asphalt 的最小案例提供曲线、场与方向数据，可用于后续熟悉字段；教学数据与真实实验、模拟输出分开保存。本轮不生成图，也不新增工作台卡片。
